# Voice AI Diary — Frontend

A mobile diary application built with **React Native and Expo**. Users can create and manage diary entries, including voice-based entries that are processed by the backend AI service.

## Tech Stack

* React Native
* Expo
* TypeScript
* NativeWind
* Tailwind CSS
* React Native Reanimated

## Getting Started

```bash
npm install
npm start
```

Then scan the QR code with **Expo Go** to run the application.
